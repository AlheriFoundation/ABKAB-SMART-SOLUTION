# AB-KAB media library

Add approved AB-KAB media here using descriptive filenames. Keep large videos optimized and provide a matching poster image where possible.

Suggested folders:

- `company/` — company, office and workspace photos
- `services/` — printing, design, computer and networking photos
- `portfolio/` — verified project screenshots and project media
- `videos/` — approved company and portfolio videos
- `founder/` — reserved for the future owner/founder content

The reusable configuration lives in `../js/media-system.js`. Empty slots are intentional until real media is supplied.
